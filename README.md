-Reflexión Profesional

8-Código abierto: Millones de proyectos en GitHub son de código abierto (cualquiera puede ver y contribuir al código). ¿Qué beneficios y riesgos identificas en compartir tu código públicamente? ¿Te sentirías cómodo compartiendo tus proyectos escolares de esta manera?

9-Historial de cambios: Git mantiene un registro completo de todos los cambios realizados en un proyecto, incluyendo quién hizo cada cambio y cuándo. ¿Cómo crees que esto afecta la responsabilidad individual en un equipo? ¿Es esto positivo o puede generar presión adicional?
